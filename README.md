# ReBook

ReBook is a static web-based platform for donating, borrowing, and sharing books within a community. The project promotes literacy by helping users donate unused books, browse available titles, support book access for others, and manage borrowing and donation requests.

## Project Overview

This project is designed as a web development website for a community book-sharing system. It includes public pages for browsing books, learning about the organization, contacting the team, donating books or money, and creating an account.

## Main Features

- Book browsing and viewing
- Book donation and monetary donation forms
- Borrow request flow
- Login and sign-up pages
- Contact and inquiry form
- Admin management pages for books, users, donations, and borrowing

## Project Structure

- `Homepage.html` — landing page
- `about.html` — about the organization
- `books.html` — book catalog
- `donate.html` — donation page
- `borrow.html` — borrowing page
- `contact.html` — contact form
- `login_and_signup_page.html` — authentication page
- `admin-*.html` — admin dashboard and management pages
- `css/` — stylesheet files
- `assets/` — images and design assets

## How to Run

Because this is a front-end static website, you can run it by opening any of the HTML files in a browser.

Recommended:

1. Open `index.html` or `Homepage.html` in your browser.
2. Use the navigation links to explore the pages.

## Technologies Used

- HTML
- CSS
- JavaScript
- Static web pages

## Notes

This is a front-end project intended for learning and presentation. It does not include a database or backend server yet.
